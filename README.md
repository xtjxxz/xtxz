## ✨ 特性

- **本站特色**：提供 Windows 10 LTSC 22H2、Windows 11 LTSC 26H2 等本站特色镜像，支持镜像下载
- **官方**：官方镜像均来自官方渠道，纯净无捆绑、无修改
- **免费不限速**：无需注册登录，无速度限制，支持断点续传
- **支持分块下载**：推荐使用文件分块下载工具，速度更快、更稳定
- **暗色模式**：支持亮色 / 暗色主题切换，保护视力
- **响应式设计**：适配桌面端和移动端，随时随地下载
- **暗色模式**：支持亮色 / 暗色主题切换，保护视力

## 🚀 快速开始

### 方式一：浏览器直接下载

1. 访问 [官方站点](https://xtxz.cc.cd/) 或 [社区站点](https://xtjxxz.github.io/xtxz/)
2. 找到需要的系统版本，点击 **「立即下载」**
3. 在新页面中点击下载按钮，保存文件即可

### 方式二：分块下载（推荐，速度更快）

1. 下载并安装 [文件分块下载工具](https://fkxz.zhshh.cn/download)
2. 在首页点击 **「复制分块下载链接」**
3. 将链接粘贴到下载工具中开始下载

> 详细教程请查看 [使用教程](https://xtxz.cc.cd/tutorial.html)
